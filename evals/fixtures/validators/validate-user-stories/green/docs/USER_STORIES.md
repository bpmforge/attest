# User Stories

## US-01 Checkout

Source: UC-01

As a registered user, I want to check out my cart so that I receive my order.

**Acceptance Criteria**

Given I have items in my cart
When I click "Checkout" and confirm payment
Then an order confirmation page renders with an order id

## US-02 Browse catalog

Source: UC-02

As a guest, I want to browse the product catalog so that I can decide what to buy.

**Acceptance Criteria**

1. The homepage loads the product grid within 2 seconds
2. Each product card shows a name, price, and thumbnail
3. Clicking a product card opens its detail page
