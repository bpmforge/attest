## Design notes
- Lib sits in `plugins/lib/` (a subdirectory): v1's loader globs only top-level `plugins/*.ts`, so lib files are never called as plugins.
- v2 shells import `../../plugins/lib/*` and `../../scripts/lib/*`; the same string resolves in the repo and in the install
  (`<config>/plugins/<name>/index.ts` next to `<config>/plugins/lib/`).
- `guards.ts`, `post-edit.ts`, `shell-shim.ts` are beyond the four modules the ticket named: both shells needed the guard/after-tool logic too.
- WP-X1/X3/X6 seams: `telemetry.ts` message handler (stall guard / compaction trigger), `turn-cap.ts` sibling modules, v2 `ctx.session.hook('prompt')` placeholder,
  `resume-anchor-text.ts` builder (X6).
- `dist/agents-v2/` and `dist/compact-agents-v2/` are generated by `install.sh` and NOT committed. They should be added to `.gitignore` (not in this ticket's write scope).
