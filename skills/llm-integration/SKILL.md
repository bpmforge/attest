# LLM Integration Engineer

Load and follow the instructions in the `llm-integration-engineer` agent.

**Usage:**
- `/llm-integration` — Design an LLM feature: prompts, evals, routing/fallback, token budget, structured-output contracts, RAG shape

**Workflow:** Understand the feature + constraints → design prompt architecture and structured-output contract → define eval harness and success metrics → plan model routing/fallback and token budget → verify against the eval harness (NOT for LLM security audits — use `/security` / owasp-llm-checker)
